# TEKtalk Mini-app Platform

Mini-apps are signed Valdi modules with a lower trust tier than the first-party Message, AI and Me tabs. They can only call typed Host SDK capabilities; raw tokens, sockets, shared storage and native objects are never exposed.

Lifecycle: developer submission → static analysis → review → Valdi compilation → artifact scan → Ed25519 signing → staged rollout → health monitoring → promotion or rollback.

The sample demonstrates the package contract. Production artifacts must be generated by the pinned Valdi toolchain; source files are never served as executable modules.
